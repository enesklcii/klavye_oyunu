# 🚀 PyType Pro — Arcade Klavye & Refleks Oyunu

Python ve **Pygame** kullanılarak modüler mimariyle geliştirilmiş, ZType tarzı uzay temalı hızlı yazma (typing) oyunu.

## ✨ Özellikler
* **Canlı WPM & İsabet Ölçümü:** Dakika başına kelime hızını (WPM) ve tuş isabet yüzdesini anlık hesaplar.
* **Özel Güçlendirmeler (Power-Ups):** `bomba` (ekran temizleme), `yavaslat` (zamanı yavaşlatma) ve `kalkan` (+1 can) kelimeleri.
* **Kombo & Parçacık Efektleri:** Hatasız serilerde puan çarpanı ve neon patlama kıvılcımları.
* **Kalıcı Rekor Sistemi:** En yüksek skor ve WPM değerlerini yerel olarak kaydeder.

## 🛠️ Kurulum ve Çalıştırma
```bash
git clone https://github.com
cd pytype-klavye-oyunu
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
